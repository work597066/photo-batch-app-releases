# subtitle-capture｜擷取影片硬字幕

適用：字幕直接燒在影片畫面裡、沒有字幕檔、影片沒加密（canvas 讀得到畫面）。
第一個用途：知識衛星課程 https://sat.cool/classroom/42 （要登入已購課帳號）。

## 做法
1. 使用者自己在電腦瀏覽器登入 sat.cool，打開要擷取的單元（網站限制同一帳號一次只能在一台設備登入）。
2. 在該分頁執行 `subcap.js` 全部內容（開發者工具 Console，或由 Claude in Chrome 代為執行）。
3. 影片會靜音、2 倍速播完；每次字幕換句截一張字幕帶，最後自動下載長圖
   `…_subs_01of03.png`（每張 30 句，左側黃字是影片時間）。
4. 把長圖交給 Claude 讀，整理逐字稿與重點摘要。

只存字幕帶截圖，不下載影片本身。

## 調整
執行前先設定，例如：
```js
window.SUBCAP_OPTS = { rate: 1.5, top: 0.8, bright: 210 };
```
- `top` / `bottom`：字幕帶位置（佔畫面高度比例，預設 0.78～1.0）
- `bright`：白字亮度門檻；字幕不是白字時要調
- `changeRatio`：換句判斷靈敏度
- 中途結束並下載：`subcap.finish()`

## 驗證狀態（2026-11-27）
- 已驗證：自製 640x360 測試影片（彩色移動背景＋白字黑邊中文字幕 5 句），在 Chromium 中抓到 5 句、時間正確、文字可讀。
- 尚未驗證：sat.cool 真實課程。若投影片背景是大片白色，白字判斷可能失準，第一個單元要先看結果再調 `top`、`bright`。
