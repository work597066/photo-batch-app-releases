## 1. App 一句話

選取手機照片（截圖）後，依拍攝時間排序，輸出 ZIP、PDF、JSON。**原始照片只複製，不會刪除或修改。**

## 2. 完整操作流程

1. 開啟 App → 首頁
2. 按「添加照片」選照片（可一次多選）
3. 照片自動依拍攝時間由早到晚排序，重複的照片自動略過
4. 逐張預覽，在右側勾選要排除的照片 → 按「確認排除勾選照片」
5. （可選）進設定頁，勾選本批要寫入 JSON 的資料 → 按「確認本批設定」
6. 按「整理並建立 ZIP」→ 確認最終清單 → 「確認並整理」
7. 完成後選「儲存 ZIP 到手機」或「分享 ZIP」

## 7. 輸出的 ZIP 裡有什麼

| 檔案 | 內容 |
|---|---|
| `originals/` | 依拍攝時間命名的原始照片副本，照片不重新壓縮 |
| `batch_001.pdf` | 每張照片一頁 |
| `batch_001.json` | 每張照片的資料（依設定頁勾選的項目） |
| `README.txt` | 批次說明 |

照片缺資料時，JSON 會寫明原因，例如：照片未提供可確認的拍攝日期、照片未提供 GPS 緯度、未執行地點名稱或地址分析。

## 8. 安全承諾（App 各處反覆出現的說法）

- 原始照片只複製，不會刪除或修改
- 排除、移除、清空都只影響 App 內的清單
- 未勾選的資料不會輸出
- 不會分析地點名稱或地址
- 更新只用 HTTPS，下載後會驗證檔案

## 9. 和「抓圖」的連結

- 圖知能從檔名讀出拍攝時間，支援三種開頭：`IMG`、`Screenshot`、`抓圖`（格式：`抓圖_年月日_時分秒`）。抓圖截下的照片，可以直接交給圖知依時間排序。
- 手機需求：Android 8.0（API 26）以上可安裝。抓圖的需求是 Android 11 以上。
